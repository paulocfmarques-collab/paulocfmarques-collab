## 🔭 Projetos em Destaque

### MAC Presence Exporter

Sistema de monitoramento de presença de dispositivos em rede utilizando:

- Python
- PostgreSQL
- Prometheus
- Grafana
- Nmap
- Arp-Scan
- Raspberry Pi

Principais funcionalidades:

- Descoberta automática de dispositivos
- Monitoramento por MAC Address
- Histórico de presença
- Tempo online e offline
- Exportação de métricas para Prometheus
- Dashboards Grafana
- Persistência de dados em PostgreSQL
