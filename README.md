## 👋 Sobre mim

Sou um **Engenheiro de Software Embarcado** com **+15 anos** de experiência no desenvolvimento de sistemas críticos, com especialização em:
- Software embarcado, firmware e RTOS
- Sistemas de rede e IoT
- Observabilidade e automação operacional
- Liderança técnica e mentoria

Atuo como **Team Leader** em sistemas de alta confiabilidade na **AEL Sistemas** e também como **Professor Universitário**, combinando excelência técnica com desenvolvimento de pessoas.

<div align="left">

#### 🔷 [M5NanoC6 Wi-Fi](https://github.com/paulocfmarques-collab/M5NanoC6_wifi)

- ⚡ Provisioning Wi-Fi com acesso point
- 📡 Conectividade robusta e fallback
- 🎛️ Interface de comando/status
- 🔍 Diagnósticos embarcados

**Stack:** `C++` `ESP32` `Arduino` `Wi-Fi` `OLED`

---

#### 🔷 [ESP32 WiFi + Ethernet + SD Card + OLED Control Platform](https://github.com/paulocfmarques-collab/esp32_wifi_eth_sdcard_P4)
Plataforma industrial robusta combinando múltiplos canais de conectividade, logging persistente e diagnóstico em tempo real.
- 🔀 Dual networking (Wi-Fi + Ethernet)
- 💾 SD card logging e armazenamento
- 📟 OLED diagnostics display
- 📤 UDP command interface (port 4210)
- 🔐 Persistent credentials com reset workflow

**Stack:** `C++` `ESP32-P4` `Ethernet` `SD Card` `UDP` `NTP` `GPIO`

---

#### 🔷 [ESP32-P4 Wi-Fi & UDP Control Gateway](https://github.com/paulocfmarques-collab/esp32_wifi_P4)
Gateway configurável com provisioning Wi-Fi, interface UDP, LED control avançado e telemetria completa.
- 🎯 Wi-Fi SoftAP provisioning
- 🕹️ UDP command processing
- 💡 LED control (blink finite/contínuo)
- 🌡️ Telemetria (CPU, RAM, temp, uptime)
- 🔄 GPIO reset recovery workflow

**Stack:** `C++` `ESP32-P4` `Wi-Fi` `UDP` `HTTP` `SSD1306 OLED`

---

#### 🔷 [ESP32 Bluetooth Remote Control and System Monitor](https://github.com/paulocfmarques-collab/esp32_bluetooth)
Firmware Bluetooth SPP para controle remoto bidirecional com diagnósticos embarcados e monitoramento de sistema.
- 📱 Bluetooth Classic SPP
- 🎮 LED control com blinking assíncrono
- 🔍 CPU, RAM, flash, uptime diagnostics
- 💬 Text-based command/response protocol
- 📞 Suporte smartphone e desktop terminal

**Stack:** `C++` `ESP32` `Bluetooth` `GPIO` `millis() timing`

---

#### 🔷 [ESP32 Central](https://github.com/paulocfmarques-collab/esp32_central)
Central de controle touchscreen para monitoramento e comando de múltiplos nós ESP32 via rede local Wi-Fi.
- 🖥️ TFT/XPT2046 touchscreen interface
- 🎯 Multi-node selection e dispatch
- 📤 UDP command/response protocol
- 🔌 Provisioning via captive portal
- 🔐 NVS persistent credentials

**Stack:** `C++` `ESP32` `Wi-Fi` `UDP` `TFT_eSPI` `XPT2046` `Preferences`
