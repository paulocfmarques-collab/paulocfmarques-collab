## Sobre mim

Sou um Engenheiro de Software Embarcado com mais de 15 anos de experiência no desenvolvimento de sistemas críticos, com foco em software embarcado, redes, IoT e automação de infraestrutura.

Atualmente atuo como Team Leader em sistemas de alta confiabilidade e também como professor universitário, trabalhando com liderança técnica, arquitetura de software, desenvolvimento em C/C++, integração de sistemas e melhoria contínua de processos.

Minha atuação combina:

- software embarcado e firmware
- sistemas em tempo real
- redes e protocolos de comunicação
- IoT e dispositivos conectados
- observabilidade e monitoramento
- automação operacional e tooling

> Leadership, rigor técnico e aprendizado contínuo são a base para construir software confiável e times de alto desempenho.

## Repositórios em destaque

### [M5NanoC6 Wi-Fi](https://github.com/paulocfmarques-collab/M5NanoC6_wifi)

Projeto de conectividade Wi‑Fi para M5NanoC6 com foco em diagnóstico, controle local e integração de periféricos embarcados.

### [ESP32 WiFi + Ethernet + SD Card + OLED Control Platform](https://github.com/paulocfmarques-collab/esp32_wifi_eth_sdcard_P4)

Plataforma robusta para controle embarcado com Wi‑Fi, Ethernet, armazenamento em SD, OLED e comandos UDP.

### [ESP32-P4 Wi‑Fi & UDP Control Gateway](https://github.com/paulocfmarques-collab/esp32_wifi_P4)

Gateway configurável com provisioning Wi‑Fi, interface UDP, painel diagnóstico e telemetria de runtime.

### [Network Discovery for Prometheus](https://github.com/paulocfmarques-collab/network-discovery-prometheus)

Automação em Python para descoberta de redes, inventário de ativos e geração de targets para Prometheus.

### [MAC Presence Exporter](https://github.com/paulocfmarques-collab/mac-presence-exporter)

Monitoramento de presença de dispositivos com persistência em PostgreSQL e exportação de métricas para Prometheus/Grafana.

### [Network Discovery Inventory](https://github.com/paulocfmarques-collab/windows_discovery)

Ferramenta de inventário de rede para descoberta de dispositivos, verificação de MAC/IP e enriquecimento de dados.

### [ESP32 Bluetooth Remote Control and System Monitor](https://github.com/paulocfmarques-collab/esp32_bluetooth)

Firmware com comunicação Bluetooth para controle remoto, diagnósticos embutidos e monitoramento de sistema.

### [ESP32 Central](https://github.com/paulocfmarques-collab/esp32_central)

Central de controle baseada em ESP32 para comando e monitoramento de nodos remotos via rede local.

### [ESP32 Comm](https://github.com/paulocfmarques-collab/esp32-Comm)

Cliente Windows WinForms para comunicação bidirecional com dispositivos ESP32 via UDP.

### [TIniFile](https://github.com/paulocfmarques-collab/inifiles)

Biblioteca leve em C++ para manipulação de arquivos INI com zero dependências de runtime.
